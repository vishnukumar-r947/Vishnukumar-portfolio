# Portfolio Assets Instructions for Vishnukumar R

Welcome to your personal portfolio website assets folder!

### 1. How to add your real Profile Photo
1. Save your photograph inside this `assets/` folder with the filename:
   `profile.jpg` (or `profile.png`)
2. The website is pre-configured to immediately load `assets/profile.jpg` into the 3D glassmorphic hero frame.
3. If the file is not yet added, the website automatically displays the sleek monogram avatar without breaking.

### 2. How to connect your Resume PDF
1. Save your resume PDF file inside this `assets/` folder with the filename:
   `Vishnukumar_R_Resume.pdf`
2. All "Download Resume" buttons throughout the website (Hero, Navbar, About) are connected to download or view this file directly.

### 3. Contact & Social Links
To customize your LinkedIn, GitHub, LeetCode, Email, or Phone numbers, open `js/portfolio-data.js` and edit the values.
